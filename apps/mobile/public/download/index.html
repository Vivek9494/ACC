ASC Broadcast

Score matches and run the live stream overlay from your computer.

Download for Mac macOS 11+ · Apple Silicon & Intel Download for Windows Windows 10/11 · 64-bit

Mac

  1. Open the downloaded ASC-Broadcast-mac.dmg.
  2. Drag ASC Broadcast into the Applications folder.
  3. Open it from Applications. If macOS says it "could not verify" the app, click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway next to ASC Broadcast. You only need to do this once.

Windows

  1. Run the downloaded ASC-Broadcast-Setup-win.exe.
  2. If Windows shows "Windows protected your PC", click More info → Run anyway.
  3. Follow the installer, then open ASC Broadcast from the desktop shortcut.

You'll also need

  1. OBS Studio installed for streaming.
  2. Your ASC login — sign in inside the app.
